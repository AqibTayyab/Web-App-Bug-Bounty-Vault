# Web Application Bug Bounty Vault

Welcome to your personal **Web Application Bug Bounty Learning and Testing Vault**.

This vault is designed for **authorized security testing only**. Use it on bug bounty programs, your own systems, lab environments, or systems where you have explicit written permission.

## How to use this vault

1. Start with `01 Getting Started`.
2. Follow `02 12-Month Roadmap`.
3. Before touching any real target, read `03 Legal and Ethical Rules`.
4. Use `04 Master Testing Checklist` during every engagement.
5. Keep notes in `99 Templates`.

## Core principle

A bug bounty hunter does not simply run tools. A good hunter:

- Understands the application.
- Maps its users, roles, data, and workflows.
- Identifies trust boundaries.
- Tests assumptions systematically.
- Proves real impact.
- Writes a clear, professional report.

## Important safety rule

Never test a system without permission. A public website is not automatically a legal target. Always follow the bug bounty program’s scope, rules, and disclosure policy.
