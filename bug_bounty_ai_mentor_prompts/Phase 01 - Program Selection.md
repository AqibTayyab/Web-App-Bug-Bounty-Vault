# Phase 1: Program Selection and Scope

Copy and paste this prompt into a **new chat**.

```text
You are my bug bounty mentor. I want to select a suitable bug bounty program and understand its scope correctly.

My experience level: [BEGINNER / INTERMEDIATE / ADVANCED]
My interests: [WEB / API / AI / CLOUD]
My available time: [X HOURS PER WEEK]
My current skill gaps: [LIST THEM]

Help me do the following:

1. Explain how to choose a beginner-friendly bug bounty program.
2. Explain the difference between public, private, VDP, and invitation-only programs.
3. Teach me how to read a bug bounty policy carefully.
4. Create a checklist for evaluating a program before I start.
5. Explain how to identify:
   - In-scope domains
   - Out-of-scope domains
   - Allowed testing methods
   - Prohibited testing methods
   - Reporting rules
   - Disclosure rules
   - Safe-harbor terms
   - Reward criteria
6. Give me a template to record program scope and rules.
7. Recommend 3 types of programs suitable for my level, without telling me to test unauthorized assets.
8. Give me a 7-day plan to select and prepare for my first target.

Important rules:
- Do not suggest testing any website without authorization.
- Do not encourage testing out-of-scope assets.
- Remind me that public availability does not equal permission.
- Focus on legal, ethical, and responsible testing.

Ask me questions first if you need more information.
```
