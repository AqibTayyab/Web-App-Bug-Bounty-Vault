# Bug Bounty AI Mentor Prompt Pack

This folder contains ready-to-paste prompts for using an AI assistant as your **bug bounty mentor**.

Use one prompt per new chat. This keeps each chat focused and prevents long conversations from losing context.

## How to use

1. Open a new AI chat.
2. Copy the prompt for the phase you are working on.
3. Paste it into the chat.
4. Replace every `[BRACKETED PLACEHOLDER]` with your real information.
5. Ask the AI to teach, review, plan, or debug—not to perform unauthorized testing.
6. Save the AI’s useful output in your Obsidian vault.

## Safety rule

Only use these prompts for:

- Your own systems
- Legal lab environments
- Authorized bug bounty programs
- Targets explicitly listed in a program’s scope

Never ask an AI to help you attack, access, disrupt, or exfiltrate data from a system you are not authorized to test.

## Recommended workflow

```text
Phase 0: Mentor setup
Phase 1: Program selection and scope
Phase 2: Reconnaissance
Phase 3: Application mapping
Phase 4: Authentication testing
Phase 5: Authorization testing
Phase 6: API testing
Phase 7: Business logic testing
Phase 8: Input validation testing
Phase 9: Cloud and configuration testing
Phase 10: LLM/GenAI testing
Phase 11: Vulnerability validation
Phase 12: Report writing
Phase 13: Submission and follow-up
Phase 14: Learning review
```

## Mentor style

Every prompt asks the AI to act as a mentor, not merely an answer machine. The mentor should:

- Explain the reason behind each step
- Ask clarifying questions
- Give practical exercises
- Correct mistakes
- Prioritize impact
- Enforce authorization and scope rules
- Help you build a repeatable methodology
