# Quick Prompts

Use these short prompts inside an existing mentor chat.

## Explain a vulnerability

```text
Explain [VULNERABILITY NAME] like I am a beginner. 
Include: definition, root cause, secure implementation, testing approach, impact, evidence, and common false positives.
```

## Create a test plan

```text
Create a step-by-step test plan for [FEATURE OR ENDPOINT] on an authorized target. 
Include roles, test cases, expected behavior, evidence, and impact assessment.
```

## Review my methodology

```text
Review my bug bounty methodology and identify gaps. 
Here is my process: [PASTE PROCESS]. 
Be specific and prioritize high-impact improvements.
```

## Analyze a request

```text
Analyze this HTTP request and response from an authorized target. 
Explain what is happening, identify security-relevant observations, and suggest safe next steps. 
Do not assume authorization beyond the scope I provide.

Request:
[PASTE REQUEST]

Response:
[PASTE RESPONSE]
```

## Identify attack surface

```text
Based on this application description, identify the attack surface, trust boundaries, high-value objects, and priority test cases.

Application description:
[PASTE DESCRIPTION]
```

## Create a report

```text
Turn these notes into a professional bug bounty report. 
Ask clarifying questions first. Do not exaggerate impact.

Notes:
[PASTE NOTES]
```

## Review a report

```text
Review this bug bounty report as an experienced triager. 
Identify missing information, unclear steps, weak impact explanation, and improvements.

Report:
[PASTE REPORT]
```

## Learn from a disclosed report

```text
I want to learn from this publicly disclosed bug bounty report. 
Explain the vulnerability, root cause, testing methodology, impact, remediation, and lessons I can apply to future authorized targets.

Report:
[PASTE REPORT OR LINK]
```

## Build a checklist

```text
Create a detailed checklist for testing [FEATURE / TECHNOLOGY / VULNERABILITY CLASS] on an authorized target. 
Include preparation, test cases, evidence, impact assessment, and reporting.
```

## Weekly review

```text
Review my bug bounty progress for this week.

What I studied:
[PASTE]

What I practiced:
[PASTE]

What I found:
[PASTE]

What I struggled with:
[PASTE]

Create an honest assessment and a plan for next week.
```
